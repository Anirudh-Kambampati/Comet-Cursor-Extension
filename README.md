## 🚀 Installation

### Developer Mode

1. Clone this repository

```bash
git clone https://github.com/Anirudh-Kambampati/Comet-Cursor-Extension.git
```

2. Install dependencies

```bash
npm install
```

3. Build the extension

```bash
npm run build
```

4. Open Chrome and navigate to

```
chrome://extensions
```

5. Enable **Developer Mode**

6. Click **Load unpacked**

7. Select the generated build (dist) folder.

## 🎯 Vision

Comet aims to transform the everyday browsing experience by replacing the default cursor with a polished, premium alternative inspired by celestial motion.

Rather than using traditional particle effects, Comet focuses on elegant SVG-based visuals, subtle animations, and fluid interactions to create a cursor that feels refined without becoming distracting.
